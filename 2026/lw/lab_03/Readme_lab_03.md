## 3. Математический аппарат CNN

### 3.1. Входное изображение

После `ToTensor()` серое изображение EMNIST имеет форму:

$$ X \in \mathbb{R}^{1 \times 28 \times 28} $$

где первый размер — число каналов, а два последних — высота и ширина.

После нормализации значения пикселей приводятся к удобному численному диапазону для оптимизации.

---

### 3.2. Двумерная свертка

Для одного выходного канала значение карты признаков вычисляется как локальная взвешенная сумма:

$$ Y_{c,i,j} = b_c + \sum_{d=1}^{C_{in}} \sum_u \sum_v K_{c,d,u,v} X_{d,i+u,j+v} $$

где:

- $X$ — входной тензор;
- $K$ — обучаемое ядро свертки;
- $C_{in}$ — число входных каналов;
- $c$ — номер выходного канала;
- $b_c$ — смещение;
- $Y$ — карта признаков.

Для `Conv2d(1, 16, kernel_size=3, padding=1)` сеть обучает 16 фильтров размером $3\times3$.

Число обучаемых параметров сверточного слоя:

$$ N_{conv} = (K_h K_w C_{in} + 1) C_{out} $$

Например:

$$ N_{conv} = (3 \cdot 3 \cdot 1 + 1) \cdot 16 = 160 $$

Сверточный слой использует **разделение весов**: один и тот же фильтр применяется во всех пространственных положениях. Именно поэтому свертка намного экономнее отдельного веса для каждого пикселя и каждого скрытого нейрона.

---

### 3.3. Эквивариантность к сдвигу

Свертка не является строго «инвариантной» к сдвигу. Более точное свойство — **эквивариантность к переносу**:

> если входной объект сдвинуть, соответствующая карта признаков также сдвигается.

Пулинг и обучение на аугментированных изображениях могут сделать конечный классификатор **приближенно устойчивым** к небольшим смещениям.

В практической части сравнивается точность MLP и CNN на исходных и искусственно сдвинутых тестовых изображениях.

---

### 3.4. ReLU

После свертки применяется нелинейность:

$$ ReLU(z) = \max(0,z) $$

Она сохраняет положительные активации и обнуляет отрицательные.

---

### 3.5. MaxPool2d

Для окна $2\times2$:

$$ y = \max(x_1,x_2,x_3,x_4) $$

После `MaxPool2d(2)` пространственный размер уменьшается в два раза:

- $28\times28 \rightarrow 14\times14$;
- после второго пулинга: $14\times14 \rightarrow 7\times7$.

Пулинг уменьшает вычислительную стоимость и повышает устойчивость представления к малым локальным смещениям.

---

### 3.6. Размер выхода свертки

Для одной пространственной оси:

$$ H_{out} = \left\lfloor \frac{H_{in} + 2P - D(K-1) - 1}{S} + 1 \right\rfloor $$

где:

- $H_{in}$ — входной размер;
- $K$ — размер ядра;
- $P$ — padding;
- $S$ — stride;
- $D$ — dilation.

В данной работе используется `kernel_size=3`, `padding=1`, `stride=1`, поэтому свертка сохраняет высоту и ширину.

---

### 3.7. Полносвязная сеть как базовая модель

MLP сначала превращает изображение в вектор:

$$ 1 \times 28 \times 28 \rightarrow 784 $$

Затем каждый скрытый нейрон получает отдельный вес для каждого входного пикселя.

Для слоя `Linear(784, 64)`:

$$ N_{MLP} = 784 \cdot 64 + 64 = 50\,240 $$

уже только в первом полносвязном слое.

MLP не использует явным образом локальность пикселей и пространственную структуру изображения.

---

### 3.8. Функция потерь CrossEntropyLoss

Для объекта $i$ и истинного класса $y_i$:

$$ L_i = -\log \frac{\exp(z_{i,y_i})}{\sum_{c=1}^C \exp(z_{i,c})} $$

где $z_{i,c}$ — **логит** класса $c$.

В PyTorch:

```python
criterion = nn.CrossEntropyLoss()
```

**Критически важно:** `nn.CrossEntropyLoss()` ожидает необработанные логиты. Поэтому в `forward()` учебных моделей **не добавляется `Softmax` или `LogSoftmax`**. Для получения вероятностей только при анализе прогноза можно использовать:

```python
probs = torch.softmax(logits, dim=1)
```

---

### 3.9. Обратное распространение ошибки

Оптимизатор обновляет параметры по направлению отрицательного градиента:

$$ \theta_{t+1} = \theta_t - \eta \nabla_\theta L $$

где:

- $\theta$ — параметры сети;
- $\eta$ — коэффициент скорости обучения;
- $L$ — функция потерь.

В PyTorch градиенты вычисляются вызовом:

```python
loss.backward()
```

а обновление параметров выполняет оптимизатор Adam:

```python
optimizer.step()
```

## 4. Базовая архитектура CNN

Концептуальная схема:

```text
Input 1×28×28
→ Conv2d
→ ReLU
→ MaxPool2d
→ Conv2d
→ ReLU
→ MaxPool2d
→ Flatten
→ Dropout
→ Linear
→ logits
```

Вход `CrossEntropyLoss` — **логиты**. Softmax используется только для интерпретации вероятностей после обучения.

Рекомендуемая архитектура:

```python
Conv2d(1, filters_1, 3, padding=1)
ReLU()
MaxPool2d(2)

Conv2d(filters_1, 2 * filters_1, 3, padding=1)
ReLU()
MaxPool2d(2)

Flatten()
Dropout(p)
Linear(2 * filters_1 * 7 * 7, num_classes)
```

## 10. Технические замечания

### Воспроизводимость

Фиксированный seed уменьшает случайный разброс результатов, но не гарантирует абсолютного побитового совпадения между разными версиями PyTorch, GPU и вычислительными платформами.

### Ориентация EMNIST

В ноутбуках применяется функция:

```python
def fix_emnist_orientation(img):
    img = TF.rotate(img, -90)
    img = TF.hflip(img)
    return img
```

Она используется до `RandomRotation` и делает символы удобными для визуальной проверки.

### Softmax

Не добавляйте `Softmax` в последнюю строку `forward()`, если далее используется `nn.CrossEntropyLoss()`.
